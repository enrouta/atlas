# @enrouta/types

Shared domain contracts — enums, DTOs, and response shapes — for the
[EnRouta](https://enrouta.com) spatial-safety platform. Consumed by the API and
the client apps so both sides agree on the wire format.

## Install

```bash
npm install @enrouta/types
```

## Usage

```ts
import { eAlertType, type Alert, type RiskScore } from '@enrouta/types';
```
